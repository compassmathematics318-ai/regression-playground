GENERALIZATION

Model vs. Theoretical Line

Target Line i The theoretically correct line generated by the target A and B values. This is the line your trained model is aiming to match on new x-values. Current Predictions i The line produced by the model's currently learned A and B values. Comparing it with the target line shows how closely the trained model matches new inputs. Target y i The theoretically correct y-values at the selected test x-values. These are the reference outputs used to see how closely the trained model matches the target line. Predicted y i The y-values produced by the current model at those same test x-values, using its learned A and B coefficients.
